# Vizipet

Projeto Integrador do 3º período com uma proposta social: facilitar o acesso à saúde animal para tutores de baixa renda.

## Problema

Muitos tutores não conseguem arcar com os custos de castração, consultas e exames veterinários. A proposta do Vizipet é aproximar essas pessoas de serviços veterinários e contribuir para o bem-estar animal e a castração responsável.

## Objetivos da proposta

- Facilitar a busca por clínicas veterinárias próximas ao tutor.
- Apoiar o acesso a consultas, exames e outros procedimentos.
- Ampliar o acesso à castração, especialmente para famílias de baixa renda.

Esses itens descrevem os objetivos do projeto; não representam funcionalidades já entregues neste repositório.

## Estado deste repositório

**Em estruturação.** Esta versão pública reúne a apresentação da proposta e a estrutura inicial de diretórios do backend. Os arquivos de implementação, configuração e testes ainda são predominantemente placeholders.

Ainda não há uma aplicação executável ou instruções de instalação completas nesta versão.

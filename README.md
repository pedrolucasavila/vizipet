# vizipet
Trabalho do PI- 3 período. 
  Nosso projeto tem como objetivo auxiliar tutores de animais que não possuem condições financeiras para arcar com os custos de procedimentos veterinários, especialmente a castração. Além disso, a plataforma busca facilitar o acesso à saúde animal, permitindo que os tutores encontrem clínicas veterinárias próximas à sua localização para realizar consultas, exames e outros procedimentos necessários.
  Dessa forma, o projeto busca contribuir para o bem-estar dos animais, promover a castração responsável e facilitar o acesso a serviços veterinários, principalmente para famílias de baixa renda.
